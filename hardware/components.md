# Hardware Components

This document lists the hardware used in the robot, along with the purpose of each component.

## Main Components

| Component | Model / Specification | Quantity | Purpose |
|---|---|---:|---|
| Microcontroller | Arduino Uno R3 | 1 | Main controller |
| Chassis | 2 Wheel Wooden Chassis | 1 | Robot frame |
| DC Geared Motors | Yellow TT Geared Motors | 2 | Drive the wheels |
| Wheels | 65mm | 2 | Robot movement |
| Castor Wheel | — | 1 | Robot stabilization |
| Motor Driver | TB6612FNG Dual Motor Driver Module | 1 | Controls motor speed and direction |
| Battery Holder | 18650 Battery Holder | 1 | Holds the batteries |
| Battery | 18650 | 2 | Power supply |

| Component | Quantity | Purpose |
|---|---:|---|
| Jumper wires | — | Electrical connections |

## Component Details

### Microcontroller

**Model:** Arduino Uno R3

**Purpose:**  
Acts as the main controller of the robot and executes the control program.

### Chassis

**Model:** 2 Wheel Wooden Chassis

**Purpose:**  
Provides the mechanical structure on which the motors, electronics and other components are mounted.

### DC Geared Motors

**Model:** Yellow TT Geared Motors

**Quantity:** 2

**Purpose:**  
Provide mechanical drive for the two wheels.

### Motor Driver

**Model:** TB6612FNG Dual Motor Driver Module

**Quantity:** 1

**Purpose:**  
Interfaces the microcontroller with the motors, allowing the motors to be controlled in both direction and speed.

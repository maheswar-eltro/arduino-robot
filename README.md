A custom built Arduino based robot.

## Hardware 
- Robot Chasis
- Arduino Uno R4
- 2 DC geared motors
- 2 18650 Lithium Ion Battery
- 2 65mm Wheels
- TB6612FNG Motor driver
- Wires
- Bolts & Screws
- Battery Pack
- Switch Pin
- Servo Motor

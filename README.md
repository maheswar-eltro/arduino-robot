# Arduino Robot
A custom built Arduino based robot.

## Project Status
Currently under construction

## Hardware 
- Robot Chasis
- Arduino Uno R3
- 2 DC geared motors
- Battery / Power Supply
- 2 65mm Wheels
- TB662 Motor driver
- Wires
- Bolts & Screws
- Battery Pack
- Switch Pin
- Servo Motor
